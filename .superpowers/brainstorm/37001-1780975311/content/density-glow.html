String Density & Glow

How dense and how bright? These two dials define the overall feel.

A — Sparse / Soft

~10 strings, gentle glow halo. Airy, meditative. Each string is clearly visible and readable. Good for smaller spaces.

B — Medium / Balanced (Recommended)

~20 strings, moderate glow. The current 15 bumped to 20, glow added. Closest to the reference video aesthetic. Looks great in projection.

C — Dense / Intense

~40 strings, strong bloom overlapping between strings. Creates a glowing curtain effect. Very immersive on a large projection wall.
