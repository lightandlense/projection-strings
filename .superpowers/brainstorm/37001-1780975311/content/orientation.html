Line Orientation

The reference video uses horizontal lines that deform around a body. Which direction should we go?

A — Keep Vertical

Vertical strings hang top-to-bottom. Finger plucks them like a harp. Add neon glow, more strings, color. Same interaction model, new look.

B — Switch to Horizontal

Lines run left-to-right, deform around whatever breaks the field. Closest to the TouchDesigner reference. Works beautifully with body silhouettes.

C — Grid (Both Axes)

Horizontal + vertical lines form a grid. Intersection points glow on contact. More complex, more visual density — like a fabric being pushed from behind.
